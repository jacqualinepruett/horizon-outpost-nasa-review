Horizon Outpost — Lunar Outpost Alpha

2026 NASA Space Apps Challenge — Space Mission Design Game

Developers: Jacqualine Pruett and Isabella Sherwin

Horizon Outpost is an interactive lunar survival simulation where players manage oxygen, water, food, power, crew health, and emergency situations while operating a lunar research habitat.

The game features mission planning, resource management, AURA mission alerts, rover exploration, and science objectives.

Technology: React, JavaScript, TanStack Start, and Base44.
